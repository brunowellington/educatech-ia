# Quadrinho Animado com Inteligência Artificial do NotebookLM

## 1. Sobre o projeto

Este projeto explora o uso da inteligência artificial na transformação de um desenho de quadrinho feito à mão em uma animação. A experiência foi realizada com o auxílio do NotebookLM, utilizando o desenho original como fonte para orientar a interação com a ferramenta.

## 2. Objetivo

Investigar as possibilidades criativas da inteligência artificial na interpretação de desenhos manuais e na criação de conteúdos visuais animados, refletindo sobre os resultados, as limitações e a participação humana no processo.

## 3. Fonte utilizada

A fonte inicial do projeto foi um desenho de quadrinho produzido manualmente. Essa imagem serviu como referência para a solicitação de criação da animação.

## 4. Reflexão final

A experiência permite explorar como a inteligência artificial pode apoiar processos criativos a partir de materiais produzidos manualmente. Também evidencia a importância de analisar criticamente os resultados gerados, verificar a fidelidade à ideia original e reconhecer as limitações das ferramentas utilizadas.
